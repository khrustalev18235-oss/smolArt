# СмолАрт — самостоятельный сайт

Статический сайт на HTML, CSS и JavaScript. Не требует Higgsfield, сборщика, npm или серверной базы данных.

## Запуск локально
Открой `index.html` в современном браузере. Для тестирования через локальный сервер можно выполнить:
`python -m http.server 8000`
и открыть `http://localhost:8000`.

## Публикация
Загрузите содержимое этой папки на любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages, обычный хостинг или собственный сервер.

## Что изменить перед публикацией
- SVG-иллюстрации в `assets/` — оригинальные стилизованные заглушки, а не фотографии реальных изделий. Замените их фотографиями ваших работ для максимально точного портфолио.
- Ссылки Telegram, VK и прайс-листа уже указаны в `index.html`.
- Шрифт подключается с Google Fonts; при недоступности сети используется системный запасной шрифт.
- Анимации учитывают настройку `prefers-reduced-motion`.

## Файлы
- `index.html` — содержание и структура
- `styles.css` — визуальный стиль, адаптивная вёрстка и анимации
- `script.js` — scroll-driven движение, появления секций, меню
- `assets/` — оригинальные SVG-иллюстрации и знак
